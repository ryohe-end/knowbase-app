# 本番・未公開テーマでの「表示」確認手順（バックエンド不要・実客に影響なし）

割引の実適用やポイント増減（Functions/Webhook）は**ストア全体に効く**ため本番では有効化しない。
ここでは **テスト顧客にメタフィールドを手入力**し、未公開テーマのプレビューで**表示だけ**を確認する。

前提: 顧客アカウントが **従来型(Classic)** であること（アカウント/マイページがテーマ描画される）。
新型だとアカウント系は表示されない（＝この時点で判明する）。

---

## 1. 顧客メタフィールド定義を作成（無害・一度だけ）
管理画面 **設定 > カスタムデータ > 顧客 > 定義を追加**。**各定義の「ストアフロントでのアクセス」を必ず ON**。
| 名前空間.キー | 型 |
|---|---|
| `loyalty.member_id` | 1行テキスト |
| `loyalty.rank` | 1行テキスト |
| `loyalty.rank_name` | 1行テキスト |
| `loyalty.points` | 整数 |

（synced_at は表示に不要なのでこの確認では省略可）

## 2. テスト顧客を用意し、メタフィールドを手入力
1. **顧客 > 顧客を追加** でテスト顧客を作成（自分の受信できるメールで可）。
2. パスワードでログインできるように **アカウント有効化**（招待メール→パスワード設定）。
3. その顧客の詳細ページ下部 **メタフィールド** に入力（ゴールド会員の例）:
   | キー | 値 |
   |---|---|
   | `loyalty.member_id` | `1356005646` |
   | `loyalty.rank` | `0003` |
   | `loyalty.rank_name` | `ゴールド` |
   | `loyalty.points` | `4800` |

   ※ ランク別に見た目を変えたいとき:
   - シルバー: `rank=0002` / `rank_name=シルバー`（3%）
   - ゴールド: `rank=0003` / `rank_name=ゴールド`（5%）
   - プラチナ: `rank=0004` / `rank_name=プラチナ`（10%）

## 3. 対象商品にタグを付ける
確認用の商品を1つ選び、商品タグ **`member-discount`** を付与（※値下げ中＝compare_at_priceありの商品は対象外なので、通常価格の商品を使う）。

## 4. 未公開テーマをアップロード
```
cd minefit-onlineshop
shopify theme push --unpublished --theme "loyalty-preview"
```
（または管理画面 Online Store > テーマ > テーマを追加 でzipアップロード）

## 5. プレビューしてテスト顧客でログイン
1. 管理画面 **Online Store > テーマ >（loyalty-preview）> アクション > プレビュー**。
   プレビューURL（`?preview_theme_id=...`）が開く。
2. そのプレビュー状態のまま **/account/login** へ移動し、**テスト顧客でログイン**。
   （プレビューセッションが維持されるので、未公開テーマのままログイン後の画面が見られる）

## 6. 確認ポイントと期待結果
| 画面 | 期待 |
|---|---|
| マイページ（/account） | ゴールドの**ランクバッジ**＋カードが**金系の色**、会員番号・ポイント表示、`会員番号を変更する` |
| 商品ページ（対象タグ商品） | 価格欄に **「ゴールド会員 5%OFF ＋ 会員価格 ¥2,850 ~~¥3,000~~」** |
| 商品ページ（非対象 or セール品） | 会員価格の表示なし（通常価格のまま） |
| カート | 「**ポイントを使う**」UIが表示（残高4800）。「適用」でカート属性が入る（表示のみ） |
| アカウント作成（/account/register） | 会員限定の案内・**会員番号必須**の見た目 |

## 7. この確認で「出ないもの」（正常）
- **チェックアウトの実割引**（ランク割引・ポイント利用の◯円引き）→ Functions未有効化のため出ない
- **ポイントの実増減** → 注文Webhook未登録のため発生しない
- 登録フォームの**送信成功**（会員限定ゲート）→ App Proxy未設定だとエラー表示で止まる（表示確認のみ）

これらの「実挙動」は開発ストア or go-live時の管理された少額テストで確認する。

## 8. 後片付け
- テスト顧客のメタフィールド/顧客、テスト商品タグは確認後に戻す。
- 未公開テーマは公開しない限り実客に影響しない。
